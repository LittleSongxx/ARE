📊 模块 1: Graph Rarefaction (图稀疏化)

问题

  • 大地图节点数爆炸 (>1000个)
  • Transformer 复杂度 O(N²)
  • 官方代码缺失实现

3阶段算法

  1. 锚点识别 (机器人、frontier、路口)
  2. 链收缩 (degree-2节点合并)
  3. 距离感知剪枝 (保留高价值节点)

效果

📈 模块 2: KF Reward Baseline (奖励归一化)

问题: 标准归一化失效

标准方法: r' = (r - μ) / σ 当 γ = 1.0 (无折扣): Q(s,a) = E[r] + E[Q(s',a')] 如果 r' = (r - μ)/σ: Q'(s,a) = E[(r-μ)/σ] + ... ≈ 0 + E[Q'(s',a')] → Reward 信号消失！ → Q值完全由 entropy 主导

我们的解决方案

r' = r / max(σKF, 1)

✅ 优势

  • 保留期望: E[r'] = E[r]/σ ≠ 0
  • 归一化方差: Var[r'] ≈ 1
  • 防止放大: floor=1 当 σ<1
  • 自适应: KF 跟踪非平稳统计量

训练稳定性

-40%

Policy Loss 方差降低
